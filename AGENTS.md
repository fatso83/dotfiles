# Gjennomføring
Ved oppgaver med flere steg skal agenten vedlikeholde fremdrift og gjenstående arbeid i repoet. Etter hvert delresultat skal den selv velge og gjennomføre neste nødvendige steg. Ikke avslutt med forslag til videre arbeid når dette allerede er innenfor oppdraget. Avslutt først når ferdigkriteriene er verifisert, eller en konkret blokkering krever brukerens input. Delresultater rapporteres som fremdrift underveis.

Deleger avgrensede oppgaver til underagenter når det hjelper. Én ansvarlig agent integrerer resultatene og verifiserer helheten. Bevar eksisterende brukerendringer og aldri legg hemmeligheter i Git eller logger.
